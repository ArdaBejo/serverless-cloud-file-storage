# Serverless Cloud File Storage

A serverless cloud file storage application developed for the Cloud Computing 1 term project.

## Technologies

- React
- TypeScript
- Cloudflare Workers
- Cloudflare R2
- Wrangler
- GitHub

## Planned Features

- Upload files
- List stored files
- Download files
- Delete files
- Display file metadata
- Storage usage dashboard
- Temporary secure sharing links
- Upload/download performance testing

## Current Progress

- React application created
- Cloudflare Worker API running locally
- `/api/health` endpoint working
- Cloudflare R2 bucket configured
- Worker-to-R2 binding added
- Local R2 test endpoint working
